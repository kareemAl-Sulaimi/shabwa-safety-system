# Shabwa Safety System (SSS)

**Shabwa Safety System** is a digital platform developed as a solution for the lost-and-found problem in Shabwa, Yemen.

The project is being developed as part of **Shabwa Developers Challenge 2026 — Season 1: Lost Items**.

## Project Documentation

The project's requirements, architecture, and user experience are documented separately:

* **SRS — Software Requirements Specification**
* **SAD — Software Architecture & Design**
* **UX/UI — User Experience & Design Specification**

The official project documents are available in the `docs/` directory.

```text
docs/
├── SRS/
├── SAD/
└── UX-UI/
```

## Technology Stack

* **Frontend:** React
* **Backend:** FastAPI
* **Database:** PostgreSQL
